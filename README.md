# 📡 Parabolize



O **Parabolize** é uma aplicação de flashcards desenvolvida para otimizar o processo de estudo e memorização.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando o ecossistema moderno do JavaScript:

* **Vite**: Ferramenta de build rápida e moderna.
* **React**: Biblioteca para construção de interfaces modulares.
* **JavaScript (ES6+)**: Lógica e manipulação de dados.
* **Bootstrap**: Framework CSS para layout responsivo e agilidade na UI.
* **HTML5 / CSS3**: Estruturação e estilização customizada.

---

## 🧠 Conceitos React Aplicados

O objetivo técnico deste projeto foi consolidar os fundamentos da biblioteca, demonstrando domínio em:

* **Componentização**: Divisão da interface em partes pequenas, reutilizáveis e independentes.
* **useState**: Gerenciamento de estado local para controle de interação (ex: virar o card).
* **Props & Children**: Comunicação eficiente entre componentes e criação de layouts flexíveis.
* **Renderização de Listas**: Uso de `.map()` para exibição dinâmica de dados a partir de arrays.
* **Renderização Condicional**: Lógica para alternar entre pergunta/resposta e estados da interface.
* **Inputs Controlados**: Manipulação de formulários para criação de novos cards de estudo.

---

## 🛠️ Metodologia de Desenvolvimento

Para garantir a organização e a qualidade das entregas, o projeto seguiu práticas de **Metodologias Ágeis**:

* **Scrum/Kanban**: Organização de tarefas em Sprints através de um quadro visual (To Do, In Progress, Done).
* **MVP (Minimum Viable Product)**: Foco inicial nas funcionalidades essenciais para entrega de valor imediata.

---

## 🎨 Interface (Dark Mode)

A aplicação foi desenhada com foco na experiência do usuário e redução da fadiga visual, utilizando uma paleta de cores **Dark Mode**.

## 💻 Como Rodar o Projeto

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/parabolize.git](https://github.com/seu-usuario/parabolize.git)
    ```

2.  **Entre na pasta do projeto:**
    ```bash
    cd parabolize
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```
